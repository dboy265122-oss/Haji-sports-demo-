# Haji Sports — Premium Sports Store Website

A handcrafted, premium website for **Haji Sports**, a sports equipment & sportswear retailer in Panskura, West Bengal, India.

## Business

- **Address:** Panskura - Puraton Bazar Road, Dakshin Gopalpur, Panskura, West Bengal 721139, India
- **Phone / WhatsApp:** +91 89726 34030
- **Hours:** Monday – Sunday, open till 8:00 PM

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion (animations)
- lucide-react (icons)

## Getting Started

```bash
npm install
npm run dev      # local development
npm run build    # production build
npm run preview  # preview the build
```

## Deploy on Netlify

1. Push this repo to GitHub.
2. In Netlify, "Add new site" → "Import an existing project" → pick this repo.
3. Build command: `npm run build`
4. Publish directory: `dist`
